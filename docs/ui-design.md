# UI / UX 設計

## 產品視覺方向

- 深色專業工作台，讓圖片與影片成為視覺焦點。
- 低裝飾、高資訊密度，但保持 12–16 px 主要間距。
- 強調色使用青綠色；警告使用琥珀色；錯誤使用紅色。
- 面板以 1px 邊界區分，避免每一區都成為浮動卡片。
- 字體優先使用系統 UI 字型；中文使用 Noto Sans TC 或微軟正黑體。

## 桌面版布局

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Top bar：專案名稱｜儲存狀態｜Undo/Redo｜預覽｜匯出                    │
├───────────────┬───────────────────────────────────┬──────────────────────┤
│ Shot List     │ Preview / Canvas                  │ Inspector            │
│ 01 開場       │                                   │ 基本 / 視覺 / 音訊   │
│ 02 問題       │          16:9 預覽                │ 轉場 / 備註          │
│ 03 解法       │                                   │                      │
│ + 新增鏡頭    │                                   │                      │
├───────────────┴───────────────────────────────────┴──────────────────────┤
│ Timeline：按鏡頭時長比例排列、播放頭、縮放、總時長                     │
└──────────────────────────────────────────────────────────────────────────┘
```

## 尺寸建議

- Top bar：52 px。
- 左側鏡頭清單：260 px，可縮至 200 px。
- 右側 Inspector：340 px，可縮至 300 px。
- 時間軸：168–240 px。
- 中央預覽最小寬度：420 px。
- 最低建議視窗：1180 × 720。

## 主要畫面

### 1. 專案首頁

- 最近專案列表。
- 新建與開啟專案。
- 顯示比例、鏡頭數、總時長、最近修改時間。
- 遺失素材或 migration 警告。

### 2. 編輯器

- 左側 Shot List：縮圖、鏡號、標題、時長、完成狀態。
- 中央 Preview：素材、文字卡、播放控制、目前時間。
- 右側 Inspector：分頁或手風琴欄位。
- 下方 Timeline：鏡頭片段與播放頭。

### 3. 匯出檢查

- 素材缺失。
- 旁白超時。
- 影片來源不足。
- 無障礙字幕缺失。
- 輸出格式選擇。

## Inspector 欄位順序

1. 基本：標題、時長、啟用、標籤。
2. 內容：腳本文字、畫面描述。
3. 視覺：類型、檔案、提示詞、fit、in/out。
4. 旁白：文字、音檔、聲音、offset、gain。
5. 音效：多筆列表、拖曳排序、開始時間、音量。
6. 轉場：類型與時長。
7. 備註與完成狀態。

## 互動狀態

- Hover：只增加背景對比，不位移。
- Selected：左側 3 px 強調線與明顯背景。
- Focus：2 px 可見焦點框。
- Disabled：保持可讀，透明度不低於 55%。
- Dirty：頂部顯示「尚未儲存」。
- Saving：小型進度指示。
- Error：欄位下方直接顯示原因與修正方式。

## 快捷鍵

- `Ctrl+N`：新增鏡頭。
- `Ctrl+D`：複製鏡頭。
- `Ctrl+S`：儲存。
- `Ctrl+Z / Ctrl+Shift+Z`：復原／重做。
- `Space`：播放／暫停，輸入框聚焦時除外。
- `Delete`：移至封存，需再次確認。
- `Alt+↑ / Alt+↓`：移動鏡頭。
- `[` / `]`：上一鏡／下一鏡。

## 響應式

- 900–1179 px：Inspector 變成右側抽屜，Shot List 縮窄。
- 600–899 px：上下布局，預覽在上，清單與 Inspector 使用分頁。
- 小於 600 px：只支援檢視與基本文字修改，不主打完整製作。
