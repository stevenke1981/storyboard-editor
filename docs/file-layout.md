# 專案檔案配置

```text
Storyboard-Project/
├─ storyboard.json
├─ project-notes.md
├─ 01_script/
│  ├─ outline.md
│  └─ narration.md
├─ 02_visuals/
│  ├─ images/
│  └─ videos/
├─ 03_audio/
│  ├─ narration/
│  └─ sfx/
├─ 04_exports/
│  ├─ shot-list/
│  ├─ subtitles/
│  └─ video/
├─ archive/
├─ .backups/
└─ .cache/
   ├─ thumbnails/
   └─ waveforms/
```

`.cache` 可刪除重建；`.backups` 不應納入一般素材清理。
